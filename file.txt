⏺ This is a Flask-based expense tracker web app — looks like a teaching/learning
   project with a step-by-step implementation guide.

  What it has so far:
  - A Flask app (app.py) with routes for landing, register, login, and
  placeholder routes for logout, profile, and full CRUD expense operations
  - HTML templates: landing.html, login.html, register.html, base.html
  - A database/ module with db.py (likely SQLite setup)
  - Dependencies: Flask, Werkzeug (for password hashing), and pytest for testing

  What's planned (not yet implemented):
  - User authentication (register, login, logout) — Steps 3–4
  - Expense management: add, edit, delete expenses — Steps 7–9

  It's a step-by-step tutorial project where students build a full
  authentication + expense tracking app incrementally.
